# IPM Dashboards

Interactive dashboards and data stories from the IPM (Sabancı University) Geopolitical Trade Risk Index project.

- [The risk didn't grow, it changed hands](https://sametapaydin.github.io/IPM_dashboards/storyline/), an 18-scene scrollytelling piece on Türkiye's import/export trade-risk concentration, 1995-2024, built on real BACI-derived data.
